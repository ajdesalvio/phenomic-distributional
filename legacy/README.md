# Historical material

`pre_revision/` is an unchanged snapshot of [the repository before this update](https://github.com/ajdesalvio/phenomic-distributional/tree/85827d86942cf430f6094ab16590bf91076dc6e4). Its README, relative folder structure, scripts, and artwork are preserved together. These analyses may differ from the revised manuscript; use the root README for current workflows.

Raw-image extraction and masking scripts remain here for reference and have not been newly verified. Moving the snapshot does not make its historical machine-specific paths portable. `package_v7/` preserves the superseded Figure 1 reference artwork.
